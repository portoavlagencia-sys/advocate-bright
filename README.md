# Edmom Moraes Advocacia — Verde Legal

Site institucional do escritório Edmom Moraes Advocacia.
Atuação em Direito Trabalhista, Imóveis, Sucessões e Família, no Brasil e para brasileiros no exterior.

Paleta: preto, verde da logo e branco para texto. Tipografia: Poppins.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone https://github.com/portoavlagencia-sys/advocate-bright.git
cd advocate-bright
npm i
npm run dev
```

Build:

```sh
npm run build
```
